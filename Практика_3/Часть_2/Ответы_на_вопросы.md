# Практика №3, часть 2 — ответы на вопросы

Ответы даны по **исходному** проекту `bikeproject.zip` (до модернизации).

### Приведите пример примитивного типа данных, который используется для хранения полей в классе

`int` — поле `NumGears` в классе `Bike`. Также `int frameSize` в `MountainBike`
и `int tyreWidth`, `int postHeight` в `RoadBike`.

Остальные поля (`handleBars`, `frame`, `tyres`, `seatType`, `make`) имеют тип
`String`, а это не примитив, а класс.

### Приведите пример того, где происходит конкатенация строк

В методе `printDescription()` класса `Bike`:

```java
System.out.println("\n" + this.make + "\n"
        + "This bike has " + this.handleBars + " handlebars on a "
        + this.frame + " frame with " + this.NumGears + " gears."
        + "\nIt has a " + this.seatType + " seat with " + this.tyres + " tyres.");
```

Оператор `+` склеивает строки, а число `NumGears` при этом автоматически
приводится к строке.

Такие же конкатенации есть в `printDescription()` у `MountainBike` и `RoadBike`.

### Каковы имена объектов, созданных в этой программе

В методе `main` класса `BikeDriver` создаются четыре объекта:

| имя | класс | как создан |
|---|---|---|
| `bike1` | `RoadBike` | конструктор без аргументов |
| `bike2` | `RoadBike` | конструктор с семью аргументами |
| `bike3` | `MountainBike` | конструктор без аргументов |
| `bike4` | `Bike` | конструктор без аргументов |

### Сколько конструкторов у каждого класса

| класс | конструкторов | какие |
|---|:--:|---|
| `Bike` | 2 | без аргументов; с пятью аргументами |
| `MountainBike` | 2 | без аргументов; с восемью аргументами |
| `RoadBike` | 3 | без аргументов; только `postHeight`; с семью аргументами |
| `BikeDriver` | 0 явных | компилятор добавляет конструктор по умолчанию |

### Наследование: определите супер- и подклассы

- **Суперкласс:** `Bike`
- **Подклассы:** `MountainBike` и `RoadBike` — оба объявлены как `extends Bike`

`MountainBike` и `RoadBike` друг другу не родственники: у них общий родитель,
но между собой связи нет.

### Значения стандартного велосипеда каждого типа

Из конструкторов без аргументов:

| поле | `RoadBike()` | `MountainBike()` |
|---|---|---|
| `make` | Oracle Cycles | Oracle Cycles |
| `handleBars` | drop | Bull Horn |
| `frame` | racing | Hardtail |
| `tyres` | tread less | Maxxis |
| `seatType` | razor | dropper |
| `NumGears` | 19 | 27 |
| `tyreWidth` | 20 | — |
| `postHeight` | 22 | — |
| `suspension` | — | RockShox XC32 |
| `type` | — | Pro |
| `frameSize` | — | 19 |

Объект `bike4 = new Bike()` создаётся безаргументным конструктором `Bike`,
который поля не заполняет, поэтому в выводе у него `null` и `0` — это значения
по умолчанию для `String` и `int`.
