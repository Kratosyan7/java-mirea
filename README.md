## Варианты

Практики №6 и №7 даются по вариантам — выбор по порядковому номеру
в списке группы, циклически. Для номера **14**:

| практика | вариантов | расчёт | вариант |
|---|:--:|---|---|
| №6 | 5 | `(14-1) % 5 + 1` | **4** — Builder |
| №7, структурные | 7 | `(14-1) % 7 + 1` | **7** — Proxy |
| №7, поведенческие | 10 | `(14-1) % 10 + 1` | **4** — Mediator |

## Запуск

```sh
export PATH="/opt/homebrew/opt/openjdk/bin:$PATH"
```

### Практики без пакетов (№1, №4)

```sh
cd ~/Downloads/Джава/Практика_4
javac -encoding UTF-8 -d out *.java
java -cp out TestTriangle
java -cp out TestMax
java -cp out TestColorable
java -cp out Months

```

## Отступления от методички

Там, где текст задания противоречил сам себе или давал некорректный
результат, выбрано рабочее решение, а причина записана комментарием в коде.

- **Практика №1, окончания юаней.** В задании дана только формула
  `digit = yuan % 10`, но по ней числа 11–14 получают неверное окончание
  («11 китайский юань»). Перед `switch` добавлено отсечение двух последних
  цифр 11–14; сама структура выбора по последней цифре сохранена.
- **Практика №3, `RoadParts`.** Задание требует методы, принимающие строковый
  `newValue`, но поля `tyreWidth` и `postHeight` в исходном `bikeproject`
  целочисленные, а пункт 8 требует присвоить посту значение `20`. Параметры
  оставлены `int`.
- **Практика №3, имя константы `terrain`.** Записана строчными буквами, как
  в задании, хотя по соглашениям Java константы пишут заглавными (ср.
  `TERRAIN` в `MountainParts`).
- **Практика №4, `ComparableCircle`.** Класс не объявляет `implements
  Comparable` повторно: родитель `GeometricObject` уже реализует
  `Comparable<GeometricObject>`, а один класс не может реализовать тот же
  генерик-интерфейс с двумя разными параметрами — это ошибка компиляции
  «Comparable cannot be inherited with different arguments». `Comparable`
  достаётся по наследству, переопределён только `compareTo()`.
- **Практика №5, нумерация заданий.** В методичке два раздела названы
  «Задание №1». Второй (про `MyStack`) лежит в каталогах `mystack`,
  `mystackinherit`, `mystackdeep`.
- **Практика №5, одноимённые классы.** Задание просит две разные реализации
  с одним именем (`GenericStack` на массиве и `GenericStack`-наследник
  `ArrayList`). Они разведены по пакетам `stackarray` и `stackinherit`.

## Проверено

Все 65 файлов компилируются без ошибок и предупреждений на OpenJDK 26.
Программы прогнаны с тестовыми данными, включая граничные случаи:

- BMI — все четыре диапазона интерпретации;
- окончания юаней — 1, 2–4, 5–9, 11–14, 21, 101, 111, 0, отрицательные;
- треугольник — корректный и нарушающий неравенство (`1, 2, 10`);
- месяцы — 1, 2, 12, а также 13, 0 и нечисловой ввод;
- високосность — 2024 (да), 2023 (нет), 1900 (нет), 2000 (да);
- стек на массиве — удвоение вместимости 4 → 8 → 16;
- глубокая и поверхностная копии — показано, что поверхностная протекает;
- Proxy — файл грузится только при первом `display()` (154 мс против 0 мс).
